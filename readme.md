# tpetzoldt's R-Universe Registry

[![R-universe status](https://tpetzoldt.r-universe.dev/badges/:registry)](https://tpetzoldt.r-universe.dev)

This repository contains the configuration used by [R-universe](https://r-universe.dev) to build and host my R packages collected from CRAN, GitHub, and R-Forge.

You can browse the available packages and documentation at **[tpetzoldt.r-universe.dev](https://tpetzoldt.r-universe.dev)**.

## Package List

The complete set of tracked packages is defined in [`packages.json`](packages.json). 

This file is automatically generated and updated using the script [`create-packages-json.R`](create-packages-json.R).

## How to Install Packages

To install packages primarily from CRAN while using this R-universe repository for development versions and non-CRAN packages, add the repository to your R options:

```r
options(repos = c(
  CRAN = "[https://cloud.r-project.org](https://cloud.r-project.org)",
  tpetzoldt = "[https://tpetzoldt.r-universe.dev](https://tpetzoldt.r-universe.dev)"
))

install.packages("package_name")
```

**Note:** Packages installed from R-universe are development versions built directly from source repositories and may be less stable than official CRAN releases.

## Build Frequency

Package builds are triggered automatically once every 24 hours, or whenever changes are committed to this repository or the upstream source repositories.
